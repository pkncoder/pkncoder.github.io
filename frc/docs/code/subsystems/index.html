Subsystems

What is a Subsystem

Subsystems are the base parts of the robot. On each robot there are subsystems for every different mechenism the robot does.
For examples: Drive Subsystem (also known as a drivetrain), Lift Subsystem, Claw Subsystem, etc.

Subsystems interact and piece together all of the motors, putting them in functions that can be called from anywhere (commonly in commands).
