Commands

Parts of a Command

Commands are an important part of FRC robot code. They provide mini-functions that can be used by themselves or combined together like Legos to create useful functions to your robot.

Commands commonly work by passing in one or multiple subsystems to be used to interact with everything that the command needs to (ex. motors, encoders, lights).

Commands have different parts to them:

  1. initialize()
  2. execute()
  3. end()
  4. isFinished()

The initialize method runs once when the command is first sceduled / started. This method does not run when it is first set to a binding or "initialized" in Java's terms.
